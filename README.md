# Proyek Pastodev Ai

React + TypeScript + Vite + Tailwind CSS.

```sh
npm install
npm run dev
```

## Struktur

- `src/main.tsx`, `src/App.tsx` — pintu masuk dan rute (react-router).
- `src/pages/` — satu file per halaman.
- `src/components/<fitur>/` — komponen per bagian situs; `src/components/ui/` — komponen dasar.
- `src/lib/`, `src/hooks/` — fungsi dan hook pendukung.
- `src/styles.css` — token desain (warna, radius) dan gaya global.
